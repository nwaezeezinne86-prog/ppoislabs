Post machine and tape
=====================

Purpose
-------

Model a Post machine with a two-sided infinite tape and a head.

Commands
--------

- ``L`` left, ``R`` right, ``V`` mark, ``X`` clear, ``?`` conditional jump,
  ``!`` halt.
