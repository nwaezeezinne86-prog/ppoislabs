Overview
========

Goal
----

Implement a class-value and a class-state in an object-oriented language,
demonstrating encapsulation, interface/implementation separation, unit tests,
Sphinx documentation, and a CI/CD pipeline.

Chosen language and tools
-------------------------

- Language: Python 3.13
- Tests: pytest + pytest-cov
- Docs: Sphinx (autodoc, napoleon, viewcode)
- Lint: flake8
- CI: GitHub Actions

Two variants were implemented
-----------------------------

1. **1.6.3** — a signed long integer of unbounded length.
2. **1.8.1** — a Post machine.
